# Sprints Overview

A sprint is a fixed-length timebox during which your team works on a defined set of issues. Bento supports one active sprint per board. Sprints move through three states: `Planned`, `Active`, and `Closed`.

## Who can do this

All organization members can view sprints. OWNER and ADMIN can manage them.

## Steps

1. Navigate to **Sprints** in the left sidebar (or `/board/:id/sprints`).
2. The sprints page lists all sprints for the current board — active, planned, and closed.
3. Click a sprint name to see its issues.
4. Use the sprint filter on the board to show only issues in a specific sprint.

## Troubleshooting

- **No sprints listed** — No sprint has been created for this board yet. See [Plan a Sprint](./plan.md).
- **Sprint section not visible in sidebar** — The board may be in Kanban mode (no sprint support). Check Board settings to confirm the board type.
