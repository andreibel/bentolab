# Board Permissions

Board permissions control which organization members can access a specific board. By default, a newly created board is visible only to its creator until other members are explicitly added.

## Who can do this

| Action | OWNER | ADMIN | MEMBER | VIEWER |
|---|---|---|---|---|
| Add / remove board members | ✅ | ✅ | ❌ | ❌ |
| View board member list | ✅ | ✅ | ✅ | ✅ |

## Steps

1. Navigate to the board, then open **Board settings**.
2. Select the **Members** or **Permissions** tab.
3. To add a member: search for an organization member by name or email and select them. Assign a board-level role if applicable.
4. To remove a member: find them in the board member list and select remove from the actions menu.
5. Changes take effect immediately.

## Troubleshooting

- **Member can't see the board** — Confirm they have been added to the board member list and that they have accepted their organization invitation.
- **Can't add a member** — You need OWNER or ADMIN role. The user you are adding must already be an organization member.
- **Board disappears from sidebar** — If you are removed from a board, it no longer appears in your sidebar. Ask an admin to re-add you.
